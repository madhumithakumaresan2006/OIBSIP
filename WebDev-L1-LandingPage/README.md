
# NovaTech Landing Page

A modern, responsive landing page designed for NovaTech, a fictional technology brand focused on helping people work with more clarity and intention.

## Project Overview

This project is developed as part of the Oasis Infobyte Web Development & Designing Internship, Level 1 — Task 1: Landing Page.

## Technologies Used

- HTML5
- CSS3
- Flexbox and CSS Grid
- Media Queries
- Google Fonts

## Features

- Sticky navigation bar with section links
- Attractive hero section with headline and call-to-action buttons
- Custom CSS dashboard illustration
- Features section with three feature cards
- About section
- Contact section with placeholder details
- Consistent colour palette and modern design
- Responsive layout for desktop, tablet, and mobile devices
- Semantic HTML structure
