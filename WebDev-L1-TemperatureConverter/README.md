
# 🌡️ Temperature Converter Website

## 📌 Project Overview
A simple, interactive website that converts temperatures between Celsius, Fahrenheit, and Kelvin using HTML, CSS, and JavaScript.

## 🎯 Objective
To develop a user-friendly temperature conversion tool with accurate calculations and input validation.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## ✨ Features
- Convert between Celsius, Fahrenheit, and Kelvin
- Display all three temperature units simultaneously
- Validate empty and invalid inputs
- Handle temperatures below absolute zero
- Display clear error messages
- Responsive and modern user interface

## 🧮 Conversion Formulas
- Fahrenheit = (Celsius × 9/5) + 32
- Celsius = (Fahrenheit − 32) × 5/9
- Kelvin = Celsius + 273.15
- Celsius = Kelvin − 273.15

## 🚀 How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter a temperature and select the input unit.
4. Click **Convert Temperature** to see the results.
