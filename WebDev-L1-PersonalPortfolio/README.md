
# Personal Portfolio Website

## About the Project
This is a personal portfolio website created as part of the Oasis Infobyte Web Development and Designing Internship, Level 1, Task 2.

The website introduces Madhumitha Kumaresan, showcases her skills and projects, and provides contact information.

## Technologies Used
- HTML5
- CSS3
- Java Script

## Features
- Introduction and profile photo
- About Me section
- Skills section
- Projects with GitHub links
- Contact section with email, LinkedIn, and GitHub
- Navigation links between sections
- Responsive styling for mobile screens
- White and lavender color theme
